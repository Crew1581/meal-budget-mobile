# Работа над Meal Budget Mobile

Перед работой прочитать `docs/STATUS.md`, README, связанные исходники и тесты;
проверить Git status, ветку и историю. После задачи обновить STATUS фактическим
состоянием и результатами реально выполненных проверок. Общаться по-русски.

- Сохранять чужие файлы и изменения; не пересоздавать Flutter-проект и Git.
- Не делать commit/push без явного указания пользователя; никогда не force-push.
- Backend `/home/crew/PycharmProjects/meal-budget` — только для чтения.
- Не читать `.env`, generated/, секреты и пользовательские данные. Не логировать
  токены, заголовки, анкеты, меню, тела ответов и исключения с такими данными.
- Не выполнять платные вызовы, в том числе DeepSeek. Проверки — подменённый HTTP
  или явно локальный синтетический провайдер, отдельная тестовая БД.
- Не менять существующие БД/контейнеры без необходимости и разрешения. Не делать
  разрушительных Git/filesystem/database операций.
- Проверять контракт по реальным схемам backend; не выдумывать поля и коды ошибок.
- UI, контроллер сценария, HTTP и storage разделены. Деньги не считать через float;
  стоимость и КБЖУ результата брать с сервера. Новые слои/зависимости — по необходимости.
- До POST сохранять снимок и ключ атомарно. Не повторять POST автоматически,
  не регистрировать новую установку на 401. Credentials и операции привязаны к URL.
- Проверки: `dart format --output=none --set-exit-if-changed lib test integration_test`,
  `flutter analyze`, `flutter test`, `flutter build apk --debug`.
  iOS на Linux не считается проверенным; отсутствие эмулятора не равно успешному E2E.
